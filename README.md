# Dokument LaTeX - Chińska Republika Ludowa

Projekt zaliczeniowy z przedmiotu ILAAP01 - LaTeX: tworzenie dokumentów tekstowych.

## Temat
Gospodarka, kultura i wpływ globalny Chin.

## Kompilacja
Dokument kompilowany w TeXworks (pdfLaTeX, 3x kompilacja).

## Zawartość
- Strona tytułowa
- Streszczenie
- 5 rozdziałów
- Bibliografia (7 źródeł)
- Tabela i ilustracja
